# Team Project - Python Unit Converter

## Overview

**Team Project** is a beginner-friendly Python application created as a collaborative learning initiative by **Piiyuush** and contributors.

The primary goal of this project was not only to build a functional unit converter but also to gain hands-on experience with:

* Python programming fundamentals
* Git version control
* GitHub workflows
* Team collaboration in software development
* Working with branches, commits, pull requests, and code reviews

This project served as a practical introduction to how developers work together on shared codebases while learning industry-standard development practices.

---

## Features

The converter currently supports:

### 📏 Length Conversion

Convert between:

* Centimeters (cm)
* Meters (m)
* Kilometers (km)

### ⚖️ Mass Conversion

Convert between:

* Milligrams
* Grams
* Kilograms
* Tons

### 🌡️ Temperature Conversion

Convert between:

* Celsius
* Fahrenheit
* Kelvin

### ⏱️ Time Conversion

Convert between:

* Seconds
* Minutes
* Hours
* Days
* Years

## How to Run

1. Clone the repository

```bash
git clone https://github.com/piiyuuush/team-projects.git
```

2. Navigate to the project folder

```bash
cd team-projects
```

3. Run the program

```bash
python main.py
```
